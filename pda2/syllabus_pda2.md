# Program

## SESSION 1 (LIVE IN-PERSON)

### Managing environments in Python

Learn how to manage Python environments with uv, a library designed for fast, lightweight, and reproducible dependency management. Discover how to create, activate, and maintain isolated environments to keep your projects clean and consistent.

## SESSION 2 (LIVE IN-PERSON)

### Datetimes and TimeSeries

Dive into the nuances of handling datetime data in Python using the dt attribute within pandas. This session covers parsing dates, indexing by datetime, extracting time-based features, and aggregating or resampling time series data for deeper analysis. Emphasis will be on practical applications, such as rolling averages, time-based filtering, and working with irregular time intervals in various industries.

## SESSION 3 (LIVE IN-PERSON)

### Practice: Datetimes and Timeseries

A hands-on session where students will apply datetime and time series concepts learned in the previous session. Exercises will include parsing various date formats, creating time-based indices, resampling data, and performing rolling calculations to solidify understanding of time series manipulation in pandas.

## SESSION 4 (LIVE IN-PERSON)

### Regular Expressions

Uncover the power of regular expressions (regex) for complex text manipulation within pandas using the str attribute. This session will focus on cleaning, parsing, and extracting structured information from unstructured text data. Learn to apply regex for tasks like data validation, pattern detection, and data cleaning in real-world scenarios, such as processing log files, extracting keywords, or cleaning datasets with mixed data types.

## SESSION 5 (LIVE IN-PERSON)

### Practice: Regular Expressions

A practical session where students will implement regular expressions to solve text manipulation challenges. Exercises will include cleaning messy text data, extracting specific patterns, and transforming strings within pandas DataFrames to reinforce regex skills in data preprocessing tasks.

## SESSION 6 (LIVE IN-PERSON)

### Practice: Built and automated ETL

A hands-on mini-project to build a complete ETL process using Python parametrized scripts

## SESSION 7 (LIVE IN-PERSON)

### Using APIs in Python

Learn how to work with APIs to retrieve and utilize external data sources. This session covers essential API concepts such as RESTful principles, authentication, rate limiting, and handling responses. Students will practice using Python libraries like requests to interact with APIs, preparing them to integrate valuable data from sources like weather services, financial markets, and social media.

## SESSION 8 (LIVE IN-PERSON)

### Practice: Getting External Data Through APIs

A hands-on session to apply API knowledge by fetching data from real-world sources. Students will engage in practical exercises, such as retrieving financial, social, or geographic data, parsing JSON responses, and transforming this data for analysis or visualization, simulating real data acquisition tasks in industry.

## SESSION 9 (LIVE IN-PERSON)

### Object Oriented Programming

Introduction to the principles of Object-Oriented Programming (OOP), covering classes, objects, attributes, and methods. This session focuses on how to structure Python code into classes, enabling students to build modular, reusable code. Applications include managing complex data structures and creating foundational classes that can be extended in later sessions.
